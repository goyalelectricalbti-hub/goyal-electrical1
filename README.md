# Goyal Electrical — Client + Admin Web App

GitHub Pages-ready static web app for Goyal Electrical, Bathinda.

## Client
- Responsive homepage
- Product catalogue/search/filter
- WhatsApp product enquiries
- Showroom gallery
- Contact information

## Admin
Open `admin.html`.
- Local admin login
- Gallery URL management
- Product catalogue count

**Important:** GitHub Pages is static. The included admin is browser-local and is not a secure shared database. For a real multi-device admin/client system, connect the app to Supabase/Firebase or a backend.

## Google Photos
Google Photos shared links can be viewed by anyone with the link when link sharing is enabled. Download the album photos and add them to the repository's `assets/` folder before publishing. See Google Photos help for downloading shared photos.
